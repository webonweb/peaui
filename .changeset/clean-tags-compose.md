Dodaj dostępny i responsywny FormTagsInput dla Vue, React i Web Components z walidacją przed zmianą modelu, paste, edycją, limitami, typowanymi sugestiami synchronicznymi i anulowalnym providerem asynchronicznym.

Ujednolić układ chipów, odstępy i panel sugestii ze wspólnym `PopoverOverlayer`, zachowując identyczny wygląd, pozycjonowanie i dostępność we wszystkich trzech implementacjach.

Zastąpić ciężki, rozmyty cień fokusu subtelnym dwupikselowym ringiem zgodnym wizualnie w Vue, React i Web Components.
