# PeaUI documentation

The portal uses `createWebHistory` and clean GitHub Pages URLs under `/peaui/`. The production build creates a static `index.html` for every public start, catalog, category, component and icon route, so direct refreshes work without hash routing. Polish pages use the `/pl/` path prefix, and a small compatibility redirect upgrades old `#/` links to their clean equivalents.

`sitemap.xml`, `robots.txt` and `404.html` are generated by `scripts/generate-static-pages.mjs`. Canonical URLs use `https://webonweb.github.io/peaui/`; Polish pages use the `/pl/` prefix. UI metadata is updated after every route, language and framework change.

The static entry pages prerender the document head, not the complete Vue body. Crawlers can read unique metadata and canonical URLs, while interactive documentation still requires JavaScript. A full HTML body prerender would require moving the current runtime component catalog and live renderers to an SSR-safe architecture.

The icon page documents the complete PEAUI set in functional groups. Catalog names use `category/icon-name`; search includes names and semantic tags, and the catalog renders 120 results at a time to avoid mounting more than two thousand SVG components at once.

## Dokumentacja PeaUI

Portal korzysta z `createWebHistory` i czystych adresów GitHub Pages pod `/peaui/`. Build produkcyjny tworzy statyczny plik `index.html` dla każdej publicznej strony startowej, katalogu, kategorii, komponentu i ikon, dlatego bezpośrednie odświeżenie działa bez routingu hash. Polskie strony korzystają z prefiksu `/pl/`, a małe przekierowanie zgodności zamienia stare linki `#/` na ich czyste odpowiedniki.

Pliki `sitemap.xml`, `robots.txt` i `404.html` generuje `scripts/generate-static-pages.mjs`. Adresy canonical korzystają z `https://webonweb.github.io/peaui/`, a polskie strony otrzymują prefiks `/pl/`. Metadane interfejsu aktualizują się po każdej zmianie trasy, języka i frameworka.

Statyczne wejścia renderują wcześniej sekcję `head`, ale nie pełną treść aplikacji Vue. Roboty otrzymują unikalne metadane i adresy canonical, natomiast interaktywna dokumentacja nadal wymaga JavaScriptu. Pełny prerender treści wymagałby przeniesienia obecnego katalogu komponentów i rendererów demo do architektury bezpiecznej dla SSR.
