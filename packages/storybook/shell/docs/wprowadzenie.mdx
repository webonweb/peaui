  return (
    <form onSubmit={(event) => event.preventDefault()}>
      <FormInput id="name" name="name" label="Imię"
        value={name} onValueChange={setName} />
      <ButtonAction type="submit">Zapisz</ButtonAction>
    </form>
  );
}`} />

const input = document.createElement('peaui-form-input');

input.value = '';
input.addEventListener('update:value', (event) => {
console.log((event as CustomEvent<string>).detail);
});
document.body.append(input);`} />
    <p>
      Przykłady zakładają bundler obsługujący importy CSS. Każdy import

      Przy SSR style dostarcza build klienta; Web Components rejestruj
      po stronie przeglądarki. Obiekty, tablice, funkcje i dynamiczne flagi
